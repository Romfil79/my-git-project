# Название проекта: MyFirstProject

## Краткое назначение
Данный проект создан для выполнения лабораторной работы №1. Он демонстрирует базовые навыки работы с Git и структурой каталогов.

## Требования к окружению
- ОС: Windows 11
- Установленный Git Bash
- Текстовый редактор Notepad++

## Инструкция по запуску (предварительная)
1. Склонировать репозиторий.
2. Перейти в папку src.
3. Запустить главный скрипт (будет добавлен позже).
