# Документация интеграции﻿\## 1. Архитектура взаимодействия

Система реализована по клиент-серверной архитектуре.

* \*\*Клиент (`client\_app.py`)\*\* — реализует Модуль ввода и Модуль вывода. Отвечает за взаимодействие с пользователем.
* \*\*Сервер (`api\_server.py`)\*\* — реализует Модуль обработки. Содержит бизнес-логику транспонирования матрицы.

\## 2. Схема потоков данных

Пользователь -> [Клиент: Ввод данных] -> HTTP POST (JSON) -> [Сервер: Обработка] -> HTTP Response (JSON) -> [Клиент: Вывод данных] -> Пользователь.

\## 3. Протоколы и форматы

* \*\*Протокол:\*\* HTTP (REST API).
* \*\*Метод:\*\* POST.
* \*\*Формат:\*\* JSON (application/json).
